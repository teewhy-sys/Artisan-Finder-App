# Artisan Finder

A responsive frontend web app for discovering and contacting local artisans.

## Features
- Search artisans by name, service or location
- Filter artisans by category
- Artisan profile modal
- Contact artisan button
- Responsive mobile layout
- Clean landing page and project explanation section

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## How to run
Open `index.html` in a web browser.

## Project idea
The app is designed to make it easier for customers to find skilled local service providers while giving artisans a simple online presence.
